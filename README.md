 # Projeto de Agendamento

Este projeto está sendo desenvolvido para facilitar o gerenciamento de consultas de psicologia de forma simples, organizada e eficiente, atendendo uma cliente que é psicóloga.

## Sobre o projeto

A aplicação permitirá cadastrar, consultar, atualizar e cancelar consultas de psicologia, ajudando a controlar horários e pacientes em um único lugar. Não haverá cadastro de psicólogos.

## Agendamento de clientes

A psicóloga poderá consultar os horários disponíveis e agendar, atualizar ou cancelar consultas de forma rápida e organizada.

## Funcionalidades previstas

- Cadastro de pacientes;
- Criação e consulta de consultas de psicologia;
- Organização de horários disponíveis;
- Alteração e cancelamento de compromissos;
- Prevenção de conflitos de horários.

## Status do projeto

Em desenvolvimento.
